# ROOTYM Global Export Platform

## Project Vision

ROOTYM is an AI-powered Export Operating System.

The goal is to help exporters make better business decisions,
not just manage data.

---

## Architecture Principles

- Next.js App Router
- TypeScript
- Prisma
- PostgreSQL
- Service Layer
- API Layer
- UI Layer

Never bypass the service layer.

---

## Development Rules

- One sprint at a time.
- One logical feature at a time.
- Never refactor unless explicitly requested.
- Never rename files.
- Never move files.
- Never change architecture.
- Preserve coding style.
- Build must pass after every task.

---

## Coding Standards

- PascalCase components
- camelCase functions
- Named services
- Strong TypeScript typing
- Tailwind utility classes
- Reusable components
